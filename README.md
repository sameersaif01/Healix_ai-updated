
# 🏥 Healix AI

### AI-Powered Healthcare Assistant

Healix AI is an AI-powered healthcare application that provides intelligent health insights and AI-driven healthcare assistance using Large Language Models (LLMs).

## 🚀 Features

- 🤖 AI-powered healthcare chatbot
- 📚 Medical document processing
- 🔍 Context-aware responses using RAG
- 🧠 Vector embeddings and semantic search
- 💻 Interactive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Large Language Models (LLMs)
- RAG (Retrieval-Augmented Generation)
- Vector Database

## 📂 Project Structure

```text
Healix_ai/
├── app.py
├── ingest.py
├── requirements.txt
├── data/
├── src/
└── vectorstore/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/sameersaif01/Healix_ai-updated.git
cd Healix_ai-updated
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
